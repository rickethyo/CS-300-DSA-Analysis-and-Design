# CS-300 DSA Analysis and Design

This repository contains my project work for **CS-300: Data Structures and Algorithms** at Southern New Hampshire University. The projects focus on analyzing data structures, comparing their performance, and applying an appropriate structure to solve a practical programming problem.

## Projects

### Project One: Data Structure Analysis

Project One compares three approaches for storing and managing course information:

* Vector
* Hash table
* Binary search tree

The project includes pseudocode, runtime analysis, and an evaluation of the advantages and disadvantages of each structure. Based on the requirements of the ABCU advising program, I recommended using a **binary search tree** because it provides efficient course lookup while allowing courses to be displayed in alphanumeric order through an in-order traversal.

### Project Two: ABCU Advising Assistance Program

Project Two implements the recommended binary search tree in C++. The command-line application loads course data from a CSV file and allows academic advisors to:

* Display the complete course list in alphanumeric order
* Search for an individual course
* View course titles and prerequisite information
* Validate course and prerequisite data during file loading

Additional input validation and error handling were included to improve reliability and usability.
